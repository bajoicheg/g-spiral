# G-Spiral

`G-Spiral 1.3.1` — portable Windows-приложение для структурированного опроса по типологии корпоративных культур и формирования цветного XLSX-отчёта.

## Что изменилось в 1.3.1

Hotfix 1.3.1 исправляет отображение круговой диаграммы на листе `Итоги` в Microsoft Excel. В 1.3.0 native Open XML `Pie3DChart` мог отображаться как пустой белый прямоугольник, несмотря на корректную структуру пакета и прохождение Open XML Validator.

В 1.3.1 диаграмма рендерится приложением в PNG с теми же цветами и 3D-геометрией, что и экран результатов, после чего изображение встраивается непосредственно в XLSX. Это исключает зависимость от особенностей рендера native chart конкретной версией Excel. Регрессионный тест проверяет отсутствие `ChartPart`, наличие `ImagePart` с MIME `image/png`, PNG-сигнатуру, `xdr:pic` и общую Open XML-валидность книги.

## Методика 1.3.x

Опрос состоит из семи этапов: «Атмосфера», «Система управления», «Убеждения», «Слоган», «Лидер», «Какие потребности рядового сотрудника удовлетворяет» и «В каких условиях эффективна».

На каждом этапе утверждения шести скрытых типов перемешиваются. Принадлежность к типам не раскрывается. Если одинаковое утверждение относится к нескольким типам, пользователь видит его один раз, а один выбор начисляет независимые баллы всем связанным скрытым ячейкам. При смене этапа список прокручивается вверх.

## Баллы и проценты

Модель содержит 6 типов × 7 этапов = 42 скрытые ячейки. Каждая ячейка имеет максимум 100 баллов. Если в ячейке `N` атомарных утверждений, выбранное утверждение даёт `100 / N` баллов. Внутренний расчёт выполняется без промежуточного округления.

Результат типа находится в диапазоне `0…700`. В интерфейсе и XLSX баллы отображаются округлёнными до целого. Основной процент — выраженность относительно максимума данного типа:

`ExpressionPercent = TypeScore / 700 × 100%`

Например, `425 / 700 = 60,7% выраженности`.

3D-круговая диаграмма показывает отдельный показатель — долю типа в сумме фактически набранных баллов всех типов. Обе метрики подписаны отдельно.

## Интерфейс

При запуске приложение локально подставляет имя пользователя Windows и компанию из домена Windows. Оба значения можно редактировать. Вопросы отображаются цветными карточками; декоративные цвета не связаны со скрытыми типами.

На странице результатов типы сортируются по убыванию, показываются округлённые баллы `/ 700`, процент выраженности и перспективная 3D-круговая диаграмма с отдельными боковыми гранями секторов. EXE и окна приложения используют многоцветную спиральную иконку.

## XLSX-отчёт

Книга создаётся с тремя листами в таком порядке:

1. `Таблица ответов` — аудитная матрица 6 × 7; в каждой ячейке атомарные утверждения с `✓/○` и округлённым баллом `/ 100`.
2. `Итоги` — типы по убыванию, округлённые баллы, максимум 700, процент выраженности и встроенная PNG 3D-круговая диаграмма.
3. `Детализация ответов` — иерархия `Этап → Тип → Утверждение → Ответ`, где ответ — числовое `1` или `0`.

В 1.3.x исправлена структура `sheetViews/frozen panes`, из-за которой Excel мог восстанавливать `sheet1.xml` и `sheet2.xml` в версии 1.2.0. Добавлены regression-тесты split/top-left/selection и Open XML validation.

В шапках листов записываются компания, респондент, дата/время и версия. Footer: `Сформировано G-Spiral 1.3.1`. Имя файла: `Spiral_<имя>_<компания>_<yyyy-MM-dd>.xlsx`.

## Конфиденциальность

Приложение работает локально, без телеметрии и облачных сервисов. Ответы хранятся в памяти до закрытия приложения; на диск записывается только XLSX, который пользователь явно сохраняет.

## Запуск и сборка

Windows 10/11 x64. Установка не требуется: сборка self-contained single-file.

Требуется .NET 8 SDK для сборки. GitHub Actions выполняет restore, тесты, publish, smoke-test и загрузку `G-Spiral-win-x64`; теги `v*` создают GitHub Release с `G-Spiral.exe`.

Спецификация основного релиза: `docs/superpowers/specs/2026-09-17-g-spiral-v1.3.0-release-spec.md`.

План реализации: `docs/superpowers/plans/2026-09-17-g-spiral-v1.3.0-implementation.md`.

Результаты 1.3.x не следует напрямую сравнивать с более ранними версиями без учёта изменений методики.
