# G-Spiral

`G-Spiral` — portable Windows-приложение для опроса по типологии корпоративных культур и формирования цветного XLSX-отчёта.

## Возможности

Приложение последовательно задаёт семь вопросов: «Атмосфера», «Система управления», «Убеждения», «Слоган», «Лидер», «Какие потребности рядового сотрудника удовлетворяет» и «В каких условиях эффективна». В каждом вопросе можно выбрать от нуля до шести вариантов, соответствующих типам «Бирюза», «Возможности», «Успех», «Правила», «Сила» и «Принадлежность».

Каждый выбор даёт соответствующему типу одно совпадение, поэтому итоговый результат по каждому типу находится в диапазоне от 0 до 7. Результаты сортируются по убыванию числа совпадений; при равенстве сохраняется канонический порядок типов.

На итоговом экране показываются баллы и диаграмма-бублик. Кнопка «Сохранить XLSX» создаёт книгу с двумя листами:

- `Выбранные опции` — полная матрица 6 × 7; выбранные клетки окрашены ярким цветом типа и отмечены `✓`, невыбранные показаны светлым оттенком;
- `Итоги` — отсортированная таблица баллов и долей плюс диаграмма-бублик в тех же цветах. Если пользователь ничего не выбрал, диаграмма не создаётся и выводится сообщение «Нет выбранных соответствий».

## Запуск

Нужен Windows 10/11 x64. Скачайте `G-Spiral.exe` и запустите его. Установка не требуется. Сборка self-contained и не требует отдельно установленного .NET Runtime, Python или Microsoft Excel.

## Конфиденциальность

Приложение работает локально. Оно не использует сеть, телеметрию, реестр Windows, локальную базу данных или облачные сервисы. Ответы хранятся только в памяти до закрытия приложения; на диск записывается только XLSX, который пользователь явно сохраняет.

## Сборка

Требуется .NET 8 SDK на Windows.

```powershell
dotnet restore GSpiral.sln
dotnet test GSpiral.sln -c Release
dotnet publish src/GSpiral/GSpiral.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o artifacts/publish
```

Итоговый исполняемый файл: `artifacts/publish/G-Spiral.exe`.

Для автоматической smoke-проверки:

```powershell
./artifacts/publish/G-Spiral.exe --smoke-test
```

Программа должна завершиться с кодом `0` в течение 15 секунд.

## CI

GitHub Actions на Windows выполняет restore, тесты, self-contained single-file publish и smoke-test. Успешная сборка публикует artifact `G-Spiral-win-x64`, содержащий `G-Spiral.exe`.

Согласованная спецификация находится в `docs/superpowers/specs/2026-09-16-g-spiral-design.md`.
