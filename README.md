# G-Spiral

`G-Spiral 1.2.0` — portable Windows-приложение для структурированного опроса по типологии корпоративных культур и формирования цветного XLSX-отчёта.

## Что изменилось в 1.2.0

Методика опроса стала более детальной. Исходная модель состоит из 6 скрытых типов × 7 тематических этапов = 42 скрытых ячеек. Каждая ячейка содержит 3–6 атомарных утверждений.

Пользователь проходит ровно семь этапов: «Атмосфера», «Система управления», «Убеждения», «Слоган», «Лидер», «Какие потребности рядового сотрудника удовлетворяет» и «В каких условиях эффективна». На каждом этапе утверждения всех шести скрытых типов объединяются в один список и перемешиваются в случайном порядке. В интерфейсе не показывается принадлежность утверждения к типу — ни названием, ни цветом, ни группировкой.

Порядок вариантов генерируется один раз на прохождение и сохраняется при переходах «Назад»/«Далее». При «Пройти заново» создаётся новый случайный порядок. На каждом этапе можно выбрать от нуля до всех утверждений; есть быстрые действия «Выбрать всё» и «Снять всё».

## Баллы

Каждая из 42 скрытых ячеек имеет максимум 100 баллов. Если в ней `N` атомарных утверждений, каждое выбранное утверждение даёт `100 / N` баллов. Внутренний расчёт выполняется без преждевременного округления.

Для каждого типа суммируются его семь ячеек, поэтому результат типа находится в диапазоне `0…700`. Абсолютный итоговый процент рассчитывается как:

`TypePercent = TypeScore / 42`

Это эквивалентно `TypeScore / 4200 × 100%`. Максимальный абсолютный вклад одного типа — около `16,7%`; если выбраны все утверждения всех 42 ячеек, сумма процентов шести типов равна 100%.

В 3D-круговой диаграмме показывается относительная структура фактически набранных баллов между типами, а рядом в таблице — абсолютные проценты методики.

## Интерфейс

При запуске приложение локально подставляет имя текущего пользователя Windows (`Environment.UserName`) и компанию из домена Windows (`Environment.UserDomainName`). Оба значения можно редактировать. Сетевых запросов к Active Directory или контроллерам домена нет.

Экран вопроса использует цветные карточки, но их декоративная палитра не связана со скрытыми типами. Выбор обозначается цветом, усиленной рамкой и галочкой. На итоговом экране результаты сортируются по убыванию баллов, показываются баллы `/ 700`, абсолютный процент, 3D-круговая диаграмма и блок «Ваши ответы» по всем семи этапам.

Имя и компанию можно изменить после прохождения без потери ответов. После изменения ответов или данных ранее сохранённый XLSX считается устаревшим до следующего сохранения.

## XLSX-отчёт

Кнопка «Сохранить XLSX» создаёт книгу с тремя листами:

- `Выборы` — утверждения по семи этапам в том случайном порядке, в котором они были показаны пользователю; выбранные варианты выделены, скрытый тип не раскрывается;
- `Таблица ответов` — полная аудитная матрица 6 × 7; в каждой из 42 ячеек перечислены все атомарные утверждения с `✓`/`○` и баллом ячейки `x.x / 100`;
- `Итоги` — отсортированная таблица типа, баллов, максимума 700 и абсолютного процента плюс 3D pie chart в канонических цветах типов.

В шапках записываются компания, респондент, дата/время формирования и версия G-Spiral. Footer: `Сформировано G-Spiral 1.2.0`. XLSX создаётся напрямую через Open XML SDK и не требует установленного Microsoft Excel.

Имя файла:

`Spiral_<имя>_<компания>_<yyyy-MM-dd>.xlsx`

После успешного сохранения доступны действия «Открыть файл» и «Открыть папку».

## Конфиденциальность

Приложение работает локально. Оно не использует сеть, телеметрию, реестр Windows, локальную базу данных или облачные сервисы. Имя пользователя и домен читаются только из локального окружения Windows. Ответы хранятся в памяти до закрытия приложения; на диск записывается только XLSX, который пользователь явно сохраняет.

## Запуск

Нужен Windows 10/11 x64. Скачайте `G-Spiral.exe` и запустите его. Установка не требуется. Сборка self-contained и не требует отдельно установленного .NET Runtime, Python или Microsoft Excel.

## Сборка

Требуется .NET 8 SDK на Windows.

```powershell
dotnet restore GSpiral.sln
dotnet test GSpiral.sln -c Release
dotnet publish src/GSpiral/GSpiral.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o artifacts/publish
```

Smoke-test:

```powershell
./artifacts/publish/G-Spiral.exe --smoke-test
```
