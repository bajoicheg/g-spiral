# G-Spiral 1.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v1.1 six-card-per-question survey with a seven-stage randomized atomic-option survey, score 42 hidden cells proportionally, export a three-sheet audit-ready XLSX, render sorted results with a 3D pie visualization, add an About dialog, and publish G-Spiral 1.2.0 as a portable Windows x64 EXE.

**Architecture:** Keep the .NET 8/WPF portable architecture. Replace the old `QuestionDefinition` option-per-type model with explicit stages, hidden cells, and atomic options; store selections and per-run randomized display order in `SurveyRunState`; keep scoring in a pure service; keep hidden type identity out of question view-models. XLSX remains direct Open XML generation and gains `Выборы`, `Таблица ответов`, and `Итоги` sheets plus a 3D pie chart.

**Tech Stack:** C# / .NET 8 / WPF / Open XML SDK 3.5.1 / xUnit / GitHub Actions Windows runner.

**Spec:** `docs/superpowers/specs/2026-09-17-g-spiral-v1.2.0-release-spec.md`

## Global Constraints
- Windows 10/11 x64, portable self-contained single-file `G-Spiral.exe`.
- No installer, telemetry, registry state, database, network calls, AD/DC queries, or Excel COM dependency.
- Exactly 6 hidden culture types × 7 stages = 42 hidden cells.
- Every hidden cell has 3–6 atomic options.
- Question UI must never reveal culture type through text, color, grouping, automation metadata, or order.
- Random order is generated once per survey run, stable on Back/Next, regenerated on Restart, deterministic under a test seed.
- Cell score is `100 * selectedCount / optionCount`; type score is the sum of its 7 cells; absolute percentage is `typeScore / 42`.
- Results sort by score descending, then canonical type order.
- XLSX contains exactly `Выборы`, `Таблица ответов`, `Итоги` and validates under Open XML Validator.
- Version is 1.2.0; About dialog contains Spiral Dynamics attribution and `© 2026 V. Vasilev`.
