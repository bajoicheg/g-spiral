# G-Spiral 1.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Исправить методику отображения/подсчёта, понятность результатов, 3D-визуализацию, scroll-to-top, иконку и XLSX, выпустить portable `G-Spiral.exe` версии 1.3.0.

**Architecture:** Скрытая матрица 6×7 и точная внутренняя математика сохраняются. На этапе опроса вводится слой `DisplayOptionDefinition`, который объединяет одинаковый текст в пределах этапа и хранит несколько скрытых вкладов; один пользовательский выбор включает/выключает все связанные атомарные IDs. XLSX переписывается на три листа в новом порядке с Excel-safe `sheetViews`, а UI получает отдельный псевдо-3D renderer и scroll reset.

**Tech Stack:** .NET 8, WPF, Open XML SDK 3.5.1, xUnit, GitHub Actions Windows x64, Pillow для детерминированной сборки `.ico` вне production runtime.

**Spec:** `docs/superpowers/specs/2026-09-17-g-spiral-v1.3.0-release-spec.md`

## Global Constraints

- Windows 10/11 x64, portable self-contained single-file EXE.
- Приложение остаётся offline: без AD/DC запросов, телеметрии, реестра, облака и локальной БД.
- Опрос идёт ровно по 7 этапам-столбцам; порядок отображаемых вариантов рандомизируется один раз на прохождение и сохраняется при Back/Next.
- Скрытая матрица остаётся 6×7; каждая скрытая ячейка имеет максимум 100 баллов, цена атомарного подпункта = `100 / N` для своей ячейки.
- Одинаковый текст внутри одного этапа отображается один раз, но начисляет независимые вклады всем связанным скрытым атомарным вариантам.
- Внутренние баллы считаются double без промежуточного округления; UI/XLSX отображают баллы как целые по MidpointRounding.AwayFromZero.
- Выраженность типа = `TypeScore / 700 × 100%`; pie share = `TypeScore / SumTypeScores × 100%`.
- XLSX листы строго: `Таблица ответов`, `Итоги`, `Детализация ответов`.
- `Таблица ответов` = аудитная матрица 6×7; `Итоги` = сортировка по убыванию; `Детализация ответов` = Этап → Тип → атомарное утверждение → 1/0.
- Frozen panes должны сериализоваться с корректными xSplit/ySplit, TopLeftCell, ActivePane и Selection, чтобы Excel не восстанавливал `sheetViews`.
- Версия 1.3.0 и `© 2026 V. Vasilev`.
